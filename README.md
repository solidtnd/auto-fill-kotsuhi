# auto-fill-kotsuhi

手当システムのカレンダーから出勤日と最寄り駅を読み取り、楽楽精算で交通費伝票を作って出勤日分の明細を入力し、一時保存するスクリプト。確定申請は自分で行う。

## 前提
- Node.js(20.12以上)がインストールされている環境であること。
- 手当システムに情報を入力し保存済みであること。
- ガルーンと楽楽精算にログインできること。

## コマンドの実行場所

このREADMEのコマンドは、すべて `auto-fill-kotsuhi` フォルダ(`package.json` があるフォルダ)を開いたターミナルで実行する。ターミナルは以下のいずれかの方法で開く。

- Windows: エクスプローラーで `auto-fill-kotsuhi` フォルダを開き、アドレスバーに `powershell` と入力してEnterを押す。
- Mac: ターミナルを開き、`cd ` (後ろに半角スペース)と入力してから `auto-fill-kotsuhi` フォルダをウィンドウにドラッグ&ドロップし、Enterを押す。
- VS Code: `auto-fill-kotsuhi` フォルダを開き、メニューの「ターミナル」→「新しいターミナル」を選ぶ。

## セットアップ(初回のみ)

1. 依存関係のインストール
   リポジトリをクローン(またはダウンロードして展開)した `auto-fill-kotsuhi` フォルダで、以下のコマンドを実行する。
   ```
   npm install
   npx playwright install chromium
   ```

2. `.env` の設定
   社内システムのURL情報をGit上で管理しないようにするため、`.env` にURLを設定する。
   設定するべき値は環境ごとで変わらないので設定済みのファイルを受け取るか、`.env.example` をコピーして値を設定する。

## 使い方

1. 以下のどちらかのコマンドでスクリプトを起動する
   ```
   npm run fill-kotsuhi        # 当月分
   npm run fill-kotsuhi:prev   # 前月分(月初に先月分を申請するとき)
   ```

2. ガルーン・楽楽精算それぞれ、未ログイン状態かセッション期限が切れている場合はログイン画面が開くのでログインする。
   ログインできたら自動で進む。
3. 初めての駅の組み合わせでは、乗換案内の画面で止まるため、使うルートをクリックして「決定」を押す。
   選択したルートは記録され、次回からは自動で選ばれる。
4. 以下の項目が自動で入力される。
   - 月分…対象の月の半角数字
   - 各明細
     - 日付…手当システムで選択されている日付
     - 出発…手当システムで選択されている自宅最寄り駅
     - 到着…手当システムで選択されている作業場所最寄り駅
     - 往復…「往復」(固定値)
     - 交通機関…「電車」(固定値)
     - 通勤費/交通費…「通勤費」(固定値)(初期値のまま変更されない)
5. 入力後は一時保存されて止まる。
   ブラウザを閉じるとスクリプトが終了する。
6. 必ず内容を目視で確認、自動入力できないケース(作業場所が複数ある、片道ごとにルートが異なるなど)は手動修正して申請する。

## その他のコマンド

| コマンド | 内容 |
|---|---|
| `npm run login` | ガルーン、楽楽精算の順にログインし直して保存する |
| `npm test` | テスト |
| `npm run typecheck` | 型チェック |

## ローカルに保存されるもの

- `state.json` — ログインのセッション(パスワードは含まれない)
- `route-selection.json` — 選んだルートの記録。消すと次回選び直しになる

## 制約

- 実行するたびに新しい伝票を作る。既存の伝票の修正は行われない。
- 出勤手当の1行目(1つ目の作業場所)だけを登録する。2行目以降は無視する。
- 往路と復路が「同じ」の場合にだけ対応する。
- 全出勤日を1件目と同じ経路・運賃で入力する。
